# All Tables

## `database-phase1.md`

### `persons`

Stores the core person profile, login, contact, and identity data used across the school system.

| Field | Type | Brief explanation |
|---|---|---|
| `id` | BIGINT UNSIGNED PK AUTO_INCREMENT | Unique person identifier |
| `register_id` | INT NULLABLE | Student registration number |
| `username` | VARCHAR(100) UNIQUE NOT NULL | Login name for authentication |
| `password` | VARCHAR(255) NOT NULL | bcrypt hash - never plaintext |
| `first_name` | VARCHAR(100) NOT NULL | First/given name |
| `middle_name` | VARCHAR(100) NOT NULL | Middle/father name |
| `last_name` | VARCHAR(100) NOT NULL | Family/last name |
| `email` | VARCHAR(255) NULLABLE | Contact email |
| `phone_number` | VARCHAR(50) NULLABLE | Primary phone number |
| `landline` | VARCHAR(50) NULLABLE | Landline phone number |
| `urgent_number` | VARCHAR(50) NULLABLE | Emergency contact number |
| `address` | TEXT NULLABLE | Home address |
| `birthday` | DATE NULLABLE | Date of birth |
| `gender` | TINYINT UNSIGNED NULLABLE | 0=male, 1=female |
| `picture` | VARCHAR(255) NULLABLE | Profile photo path |
| `status` | BOOLEAN DEFAULT TRUE | Active/inactive account |
| `identity_number` | VARCHAR(50) NULLABLE | National ID / passport |
| `nationality_id` | BIGINT UNSIGNED FK→nationalities NULLABLE | Person's nationality |
| `governorate_id` | BIGINT UNSIGNED FK→governorates NULLABLE | Home governorate |
| `region_id` | BIGINT UNSIGNED FK→regions NULLABLE | Home region |
| `village_id` | BIGINT UNSIGNED FK→villages NULLABLE | Home village/town |
| `blood_type_id` | BIGINT UNSIGNED FK→blood_types NULLABLE | Blood type (medical) |
| `identity_type_id` | BIGINT UNSIGNED FK→identity_types NULLABLE | ID document type |
| `created_at` | TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP | Row creation time |
| `updated_at` | TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | Last update |

| `updated_at` | TIMESTAMP | Last update time |
